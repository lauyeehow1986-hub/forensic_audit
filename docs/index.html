Lexicographic Non-Compensatory Triage

The 4+1 Forensic Audit Gates

Fatal mathematical flaws or protocol deceptions trigger immediate kill-switches. No amount of prestige or citation velocity compensates for fabricated data or unregistered subgroup spin.

G1

Retraction & EoC Status

OpenAlex · CrossRef · PubMed · Zotero · PubPeer

Real-time querying for is_retracted tags, CrossMark update policies, and formal Expressions of Concern. Immediate hard kill-switch upon confirmation.

G2

Paper-Mill & Reagent Forensics

Problematic Paper Screener · ICLAC · Blastn

Full-text linguistic screening for known paper-mill tortured phrases, cross-checking cell lines against the ICLAC register of contaminated lines, and BLAT nucleotide primer validation.

G3

Universal Statistical Audit

R 4.2+ · statcheck · scrutiny::grim_map · rsprite2

Audits every single table. Recalculates all APA NHST values for decision errors; runs GRIM test across Table 1 (demographics) and Table 2+ (outcomes) for integer impossibilities; checks Carlisle baseline uniformity.

G3.5

Universal Chart & Density Audit

R run_chart_density_audit()

Inspects scatterplots and forest plots. If authors claim broad clinical efficacy in severe spectrums, but data density in that range is < 5.0%, applies an automatic penalty (LR = 0.20).

G4

Pre-Registration & RoB 2

ClinicalTrials.gov v2 · Cochrane RoB 2

Programmatically diffs published articles against inception trial registry JSONs. Flags outcome demotion, silent switching to safety, and badging post-hoc subgroups as "pre-specified".

T2

Bayesian Credibility Score

O_1 = O_0 × ∏ LR_i

Multiplies domain Likelihood Ratios to calculate the Posterior Credibility Probability \(P(\text{Credible})\). Classifies studies from Verified Credible down to Fatally Compromised.

Zero-Hallucination Infrastructure

Authoritative MCP Servers & REST APIs

Every assertion made by the swarm is linked to programmatic machine-readable API payloads. Read the complete API Technical Reference Guide on GitHub.

⚡ Model Context Protocol (MCP) Servers

  • papers-openalex Real-time retraction verification (is_retracted: boolean), citation acceleration analysis across 250M+ scholarly works.
  • pubmed-search-mcp 41 tools for MeSH indexing, clinical trial registration extraction, conflict-of-interest declarations, and citation trees.
  • arxiv-mcp-server Preprint caching and differential formula/text analysis between preprint submission and final journal version.
  • zotero-mcp Local reference library linking, local annotated PDF extraction, and verified BibTeX deposits.
  • rstudio-mcp Direct R daemon execution bridge running statcheck, grim_map, and benford.analysis for zero-mental-math rigor.

🌐 Direct Programmatic REST APIs

  • ClinicalTrials.gov REST API v2 Retrieves inception-timestamped protocol JSON to verify whether primary endpoints or subgroup cuts existed *prior* to patient enrollment.
  • CrossRef Works REST API CrossMark update policy tracking, official publisher deposit dates, and linked clinical registry numbers.
  • Europe PMC REST API Full-text XML/JSON retrieval, bio-entity text mining, and public funding grant cross-referencing.
  • NCBI Entrez E-utilities (efetch / esummary) Structured XML abstract segmentation and official registry databank accession tracking.
  • OpenAlex Works REST API Immediate programmatic Boolean check of retraction status and Unpaywall direct PDF resolution.
